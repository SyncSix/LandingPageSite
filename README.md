# Landing Page SITE

Landing page responsiva em HTML, CSS e JavaScript para o **SITE — Sistema Integrado de Trabalho e Estágio**.

## Identidade visual

- Fonte: **Poppins** (Google Fonts com fallback local).
- Azul institucional: `#154b6f` e azul de ação `#176d9d`.
- Laranja de destaque: `#ff7b43`.
- Fundo claro: `#f7f7f2`.


## Interações

- Navegação por âncoras internas.
- CTA **Conheça o Projeto** após a seção Problema e Solução leva a Funcionalidades.
- Abas **Aluno / Professor / Coordenação** alternam tela, título e descrição.
- Menu hambúrguer até **980 px**, com abertura/fechamento, Escape, clique fora, fechamento ao navegar e botão Voltar ao topo.
- Layout adaptado para **320 px até desktop**, incluindo cards em coluna, mockups escalonados e logo menor no cabeçalho.
- Animações respeitam preferência por movimento reduzido.
- O botão **Ver no GitHub** aponta para `https://github.com/SyncSix/site`.
